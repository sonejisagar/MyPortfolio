# Sagar Portfolio

Modern, responsive portfolio website built with React, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Customize quickly

- Update profile content in `src/data/profile.js`
- Add your profile image as `public/profile.jpg` (the app auto-falls back to `profile-placeholder.svg` if missing)
- Tweak colors and animation settings in `tailwind.config.js`

## Included sections

- About Me
- Skills
- Projects
- Experience
- Contact (email only)
